# lab4-isrpo
# Лабораторная работа №4: Unit-тесты для треугольника

Реализация вычисления **периметра** и **площади треугольника** по трём сторонам (формула Герона) с **unit-тестами**, выполненными в соответствии с методикой *ручного тестирования*, описанной в задании.


## Описание
Программа принимает три положительных числа — длины сторон треугольника `a`, `b`, `c` — и возвращает:
- **Периметр**: `P = a + b + c`
- **Площадь**: по формуле Герона  
  `s = P/2`, `S = √[s(s−a)(s−b)(s−c)]`

Проверяются граничные случаи:
- нулевые и отрицательные стороны,
- нарушение неравенства треугольника.


## Unit-тесты (ручное тестирование)

Тесты реализованы вручную — без использования `unittest`, `gtest` и прочих фреймворков, в соответствии с методикой из задания:

> *«Зная входные данные, можно вручную просчитать, какой ответ должна дать программа… сравниваем с тем, который должен быть получен».*

Файл: [`triangle_test.cpp`](./triangle_test.cpp)  
Содержит:
- корректные наборы данных (например, треугольник 3-4-5 → площадь = 6),
- проверку исключений при невалидных данных,
- функции `assertEquals()` и `assertThrows()` для автоматической валидации.
